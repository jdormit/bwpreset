# Asset and binding APIs

Use `bwgrid info` for the selected module's exact parameter names. These examples show the object-valued helpers; ordinary scalar controls remain `node.set(...)`.

## Samples and tables

```python
from bwpreset.assets import AudioFile, Sample, SamplePlayer, Multisample, Zone, Slice, SlicedSample, Wavetable

audio = AudioFile.from_file("assets/tone.wav", portable_path="assets/tone.wav")
sampler.set(SAMPLE=Sample(audio, root_key=69))
sampler.set(SAMPLE_PLAYER=SamplePlayer(playback_mode="fragments", fragments_maximum_number_of_grains=64))
sampler.set(SAMPLE=SlicedSample(audio, [Slice(0), Slice(0.5)], assignment="key_chromatic"))
sampler.set(SAMPLE=Multisample([Zone(Sample(audio), key_low=0, key_high=127)]))

table = Wavetable.from_file("assets/table.wt", portable_path="assets/table.wt")
oscillator.set(WAVETABLE=table)
wavetable_lfo.set(WAVETABLE=table)
```

Generated `Wavetable(frames)` data needs `table.write(path)` before assignment. `Multisample.from_file(path)` imports a `.multisample` archive. Sample and loop boundaries, and slice starts, use seconds. `FileReference` and `AudioFile` with explicit metadata support references whose media cannot be inspected locally. Bitwig analysis caches are generated by Bitwig, not offline by this library.

## Sources

```python
from uuid import UUID
from bwpreset.bindings import NoSource, DeviceSource, TrackSource, HardwarePort, PreferencesBus, HardwareBindings

sidechain.set(SOURCE=TrackSource(UUID(project_track_uuid), signal="audio", pre_fader=True))
note_selector.set(NOTE_SIDECHAIN=TrackSource(UUID(project_track_uuid), signal="note"))
cv_input.set(INPUT=HardwarePort("Input", "CoreAudio", machine_id, "input", device_id, (channel_id,)))
```

`PreferencesBus` represents legacy hardware-preferences buses. `HardwareBindings` holds configurations for multiple machines/APIs. Bindings require actual identifiers from the destination environment. Selecting a UUID or port from another project/machine does not create it.

## Grid slots

```python
from bwpreset.slots import Device

effect = p.slot("fx", Device.from_file("effect.bwpreset"))
lfo.route(effect["MIX"], 0.25)
p.remote(effect["MIX"], "Effect mix")
```

`Device.from_definition` can use a locally installed device definition/default settings. `p.slot_device(...)` addresses an existing slot device. Nested target paths are available from `slot_targets`/`register_slot_targets`; provide an authoritative descriptor when a controllable target lacks one. General arbitrary-device synthesis is outside the Grid-authoring scope.
